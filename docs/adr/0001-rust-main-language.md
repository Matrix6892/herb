# 0001. Rust как основной язык, один workspace
status: accepted
date: 2026-09-26

Источник: спецификация фазы 1, §3.1 (`docs/spec-phase-1.md`). Решение
принято владельцем; ADR фиксирует его и место реализации.

## Решение
Ядро, конвейер данных, генератор сайта и edge-api написаны на Rust (stable, edition 2024) в одном cargo workspace. Одна формула живёт в одном месте: `catalog-core`.

## Почему (предпосылки)
Главный риск продукта: ошибка в дозе или пересчёте. Строгие типы единиц и детерминированная арифметика снижают его сильнее тестов поверх динамического языка. Ежедневная задача и API должны работать одним бинарником без рантайма на дешёвом VPS.

## Для чего (будущее)
Фаза 3: оптимизатор корзины и суммарные дозы по стеку поверх типизированного ядра. Фаза 4: `catalog-core` в расширении браузера через WebAssembly; CI с первого дня собирает его под `wasm32-unknown-unknown`.

## Границы
Никаких вторых реализаций расчётов на другом языке.

## Что проверить, если предпосылка не подтвердится
Если WebAssembly-сборка ядра станет невозможной из-за зависимости, зависимость убирается из `catalog-core`, а не ядро переписывается.

Реализация: `Cargo.toml`, `rust-toolchain.toml`, CI-задача `wasm`.
