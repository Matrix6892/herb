# 0002. Где используются другие языки
status: accepted
date: 2026-09-26

Источник: спецификация фазы 1, §3.2 (`docs/spec-phase-1.md`). Решение
принято владельцем; ADR фиксирует его и место реализации.

## Решение
Python только в `tools/` и `research/`; JavaScript в браузере без сборщика и библиотек (`site/static/app.js`, бюджет 10 КБ); SQL только в миграциях `catalog-store`; HTML и CSS в шаблонах, один CSS-файл до 30 КБ.

## Почему (предпосылки)
Экосистема LLM/OCR в Python; первая отрисовка за секунду не требует фреймворка; декларативная схема проверяется отдельно.

## Для чего (будущее)
Страница полностью читаема без JavaScript; фаза 2 добавляет состояние в адресе тем же скриптом.

## Границы
Без TypeScript, бандлера и внешних библиотек в фазе 1. Python не пишет в базу и не участвует в ежедневной задаче.

## Что проверить, если предпосылка не подтвердится
Если JS перестанет помещаться в 10 КБ, сначала пересмотреть объём функций, затем бюджет с владельцем.

Реализация: `site/static/app.js`, `tools/serve-site.py`, `crates/catalog-store/migrations/`.
