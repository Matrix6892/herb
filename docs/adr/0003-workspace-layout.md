# 0003. Структура workspace
status: accepted
date: 2026-09-26

Источник: спецификация фазы 1, §3.3 (`docs/spec-phase-1.md`). Решение
принято владельцем; ADR фиксирует его и место реализации.

## Решение
Шесть крейтов: `catalog-core` (без IO, wasm), `catalog-store` (единственный с SQL), `feed-ingest` (формат фида сети), `site-gen` (сайт из снимка), `edge-api`, `ops-cli` (команда `vitrina`). Данные в `data/`, шаблоны и статика в `site/`.

## Почему (предпосылки)
Формулы тестируются на чистых данных; смена формата фида ломает один крейт; сборка читает только снимок и поэтому воспроизводима.

## Для чего (будущее)
Фаза 2: крейты `price-history`, `alerts`; фаза 3: `stack-optimizer`, все поверх `catalog-core`.

## Границы
`catalog-core` не получает зависимостей с IO. SQL вне `catalog-store` запрещён.

## Что проверить, если предпосылка не подтвердится
Если новому крейту нужен SQL, он получает трейт в `catalog-store`, а не свой запрос.

Реализация: `crates/*`.
