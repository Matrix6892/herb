# 0004. Единицы и числа
status: accepted
date: 2026-09-26

Источник: спецификация фазы 1, §4.1 (`docs/spec-phase-1.md`). Решение
принято владельцем; ADR фиксирует его и место реализации.

## Решение
`Mass` — целые микрограммы `u64`; `Money` — центы USD `i64`; количества `u32`; `Ratio {num, den}` — сокращённая дробь `u32`. Суммирование строк этикетки идёт точной дробью (`ExactMass`, `u128`), округление вниз до микрограмма один раз. Цена за единицу — точная дробь центов (`UnitPrice`), сравнение без переполнения. `f64` появляется только в оценках 0–100, `R_b`, медиане и выводе. МЕ — отдельный тип `Iu` без преобразования в массу; единственный путь — `IuConversion`, который создаётся только с указанием вещества, и расчёт дозы отвергает конверсию чужого вещества.

## Почему (предпосылки)
Ошибка пересчёта единиц — главный риск. Разбор строк вида `"1.5 g"` выполняется точно, значения мельче микрограмма отвергаются, а не округляются.

## Для чего (будущее)
Суммы доз по стеку и сравнение с верхними уровнями в фазе 3 без накопления ошибок.

## Границы
`f64` для доз и цен в хранилище запрещён (в схеме SQLite цены и массы — INTEGER).

## Что проверить, если предпосылка не подтвердится
Если понадобятся дробные МЕ (витамин E), тип `Iu` расширяется до тысячных долей новым ADR.

Реализация: `crates/catalog-core/src/units.rs`, `pricing.rs`.
