# 0006. Хранилище SQLite
status: accepted
date: 2026-09-26

Источник: спецификация фазы 1, §4.3 (`docs/spec-phase-1.md`). Решение
принято владельцем; ADR фиксирует его и место реализации.

## Решение
Один файл SQLite в режиме WAL, миграции только вперёд в `crates/catalog-store/migrations/NNN_*.sql`, версия в `PRAGMA user_version`. Снимок для сборки — `VACUUM INTO` в `var/snapshots/vitrina-<date>.db`, открывается только на чтение с `immutable=1`. Репозитории за трейтами `CatalogRead`, `CatalogWrite`, `EventSink`.

## Почему (предпосылки)
Сотни товаров и тысячи строк цен в год; один файл упрощает бэкап и воспроизводимость.

## Для чего (будущее)
Переход на Postgres в фазе 3 меняет один крейт.

## Границы
Прямые SQL-запросы вне `catalog-store` запрещены. Выпущенная миграция не редактируется.

## Что проверить, если предпосылка не подтвердится
Если снимок другой версии схемы открывается новым кодом, `open_snapshot` отказывает с явной ошибкой.

Реализация: `crates/catalog-store/`.
