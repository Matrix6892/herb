# 0011. Сайт: маршруты, бюджет, состояние в адресе, локализация, кнопка покупки
status: accepted
date: 2026-09-26

Источник: спецификация фазы 1, §7 (`docs/spec-phase-1.md`). Решение
принято владельцем; ADR фиксирует его и место реализации.

## Решение
Маршруты `/c/<slug>`, `/pr/<slug>/<id>`, `/how`, `/disclosure`, `/privacy`; товар без этикетки получает `product_pending.html` с `noindex`. Пресет в `?preset=`; без JS показывается пресет ветки по умолчанию. Все строки в `site/i18n/en.toml`, числа и валюта через настройки локали, CSS на логических свойствах для RTL. Один компонент `buy_button.html`: трекинговая ссылка сети, `rel="sponsored nofollow"`, раскрытие в том же блоке, `sendBeacon` до перехода.

## Почему (предпосылки)
Пути повторяют iHerb для подмены домена; первая отрисовка быстрее секунды на телефоне.

## Для чего (будущее)
Поисковые страницы и сравнение фазы 2 используют те же карточки; локализации после английского, включая RTL.

## Границы
Названия товаров и состав не переводятся. Отсутствующий ключ перевода валит сборку.

## Что проверить, если предпосылка не подтвердится
Как измеряется бюджет и как отдаются пресеты — ADR 0016.

Реализация: `site/`, `crates/site-gen/`.
