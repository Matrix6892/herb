# 0012. edge-api, хостинг и эксплуатация
status: accepted
date: 2026-09-26

Источник: спецификация фазы 1, §8, §9 (`docs/spec-phase-1.md`). Решение
принято владельцем; ADR фиксирует его и место реализации.

## Решение
edge-api на axum: `POST /api/click` и `POST /api/report`, form-urlencoded, тело до 4 КБ, 60 запросов в минуту на адрес (в памяти, адрес не сохраняется), ответ 204 без тела, HTML не отдаётся. `session_hash` = SHA-256(соль, user agent, дата UTC), 16 hex. Статика на Cloudflare Pages или аналоге за CDN; edge-api и ежедневная задача на VPS в юрисдикции из И9; секреты в `/etc/vitrina/vitrina.env`; ежедневный бэкап SQLite и `data/` на 90 дней; мониторинг возраста снимка, страницы категории и edge-api с письмом владельцу.

## Почему (предпосылки)
Единственные динамические действия фазы 1 — клики и отчёты об ошибках.

## Для чего (будущее)
Фаза 2 добавляет подписки на алерты и второй таймер.

## Границы
Никаких персональных данных; никакой отдачи HTML из edge-api.

## Что проверить, если предпосылка не подтвердится
Выбор хостинга ждёт О4; конкретные команды загрузки и уведомлений — ADR 0018.

Реализация: `crates/edge-api/`, `deploy/`.
