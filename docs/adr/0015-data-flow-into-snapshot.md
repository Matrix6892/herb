# 0015. Справочник и этикетки входят в снимок; ingest их импортирует
status: assumed
date: 2026-09-26

## Решение
`vitrina ingest` сначала проверяет файлы `data/reference/`, затем записывает
день фида, затем импортирует справочник и все этикетки из `data/labels/` в
базу (то же, что делает `vitrina import-labels`), и только после этого пишет
снимок. Снимок самодостаточен: `build` читает из него всё, включая справочник
и этикетки; из репозитория `build` берёт только шаблоны, строки и статику.

Отдельная команда `vitrina import-labels` остаётся для проверки файлов после
ручного ввода.

## Почему (предпосылки)
Ежедневная цепочка в §6 не содержит `import-labels`, а этикетки меняются
коммитами. Без импорта в `ingest` новая этикетка попадала бы на сайт только
после ручного запуска. Хранение справочника в снимке делает сборку
воспроизводимой из «репозитория и снимка» (правило 4 раздела 0).

## Для чего (будущее)
История этикеток и справочника по дням восстанавливается из снимков.

## Границы
Ошибка в любом файле справочника или этикетки останавливает `ingest` с кодом
1 до записи дня; частичного импорта не бывает (одна транзакция).

## Что проверить, если предпосылка не подтвердится
Если владелец хочет публиковать этикетки только по явной команде, импорт
убирается из `ingest`, а в таймер добавляется отдельный шаг.
