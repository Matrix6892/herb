# 0019. Одна кнопка покупки в панели выбранного товара
status: proposed
date: 2026-09-26

## Решение
На странице категории нет кнопки «Buy on iHerb» в каждой строке. Строка
выбирает товар; выбранный товар показан в панели справа (на телефоне — в
нижней панели), и только там есть кнопка покупки. Рядом с кнопкой всегда:
место товара в текущем пресете, цена за 100 мг относительно медианы,
порядковое место по цене и рейтингу, компромисс словами и раскрытие
комиссии (И4). По умолчанию выбран №1 текущего пресета.

Без JavaScript панель отрисована сервером для №1 пресета по умолчанию, а
название товара в каждой строке ведёт на страницу товара `/pr/…`, где
кнопка покупки есть (§8 спецификации).

## Почему (предпосылки)
Спецификация (§8) описывает страницу категории как список «с кнопкой
покупки» и не уточняет, одна она или в каждой строке. Сейчас кнопка
стоит в каждой строке. Бюро Горбунова («Практически в каждом проекте есть
страница с такой „батареей“ одинаковых элементов»): столбец одинаковых
кнопок не читается по вертикали, его польза низкая, и кнопку легко
перепутать с соседней. «Имеет ли смысл ставить кнопку „купить“ в списке
продуктов в интернет-магазинах?»: Горбунов поддерживает ссылку на страницу
продукта вместо кнопки в списке. Главное: владелец попросил показывать, насколько
покупка хороша. Если кнопка живёт только рядом с оценкой, ни один клик
«Buy» не случается без оценки перед глазами.

## Для чего (будущее)
Та же панель переносится на страницу товара и в расширение браузера
(фаза 4) без переделки: один компонент `buy_button.html`, как требует §8.

## Границы
Трекинговая ссылка сети, `rel="sponsored nofollow"`, событие клика через
`sendBeacon` (И3) — без изменений. Раскрытие в том же блоке, выше линии
сгиба на любой ширине: панель на широком экране липкая, на телефоне
закреплена внизу.

## Что проверить, если предпосылка не подтвердится
Метрика фазы 1 — клики «Buy» и возвраты за 30 дней. Если за две недели
после запуска доля кликов из категории заметно ниже, чем со страницы
товара, вернуть кнопку в строку (один флаг шаблона) и оставить панель
для оценки покупки.
