# Гайдлайн интерфейса

Статус: черновик, 26.09.2026. Прототипы: `design/prototypes/magnesium-ranking.html`
(приложение) и `design/prototypes/inside-the-capsule.html` (главная-история).

Принципы опираются на школу интерфейсов Бюро Горбунова («Советы», подборки
про интерфейсы, https://bureau.ru/soviet/ui/selected/). При составлении сайт
был недоступен из среды разработки, поэтому формулировки ниже — наш пересказ
по памяти, а не цитаты. Сверка с подборками — вопрос Q-UI-1 в
`docs/open-questions.md`; до неё ссылаться на конкретные советы нельзя.

Гайдлайн подчиняется спецификации (`docs/spec-phase-1.md`): инварианты И1–И10,
бюджеты §7.2 и границы фазы 1 сильнее любого правила отсюда.

## 1. Внешнее выражает внутреннее

Продукт обещает честное сравнение по тому, что внутри. Каждое такое качество
получает видимую форму, и форма не должна обещать больше, чем качество.

| Качество продукта | Как выглядит |
| --- | --- |
| Сравниваем по содержимому, а не по банке | Главное число строки — цена за 100 мг элемента, крупно и первым; цена банки мельче и ниже |
| У каждого числа есть источник | Числа с пунктирным подчёркиванием открывают карточку «откуда»: фид с датой, этикетка с проверяющим, формула |
| Неизвестное не заменяется нулём (И7) | Пунктирная пустая ячейка «unknown» и причина рядом; никогда «$0.00» и «—» без объяснения |
| Комиссия не влияет на порядок (И2) | Фраза у каждой кнопки покупки и в методике; в интерфейсе нет «рекомендуемых» и «спонсорских» мест |
| Данные свежие и честно датированы | Строка «Prices from the network feed of …» видна всегда, без наведения |
| Точность до микрограмма | Моноширинные табличные цифры, одна точность в колонке, доли не округляются молча |
| Ничего не добавляем и не выбрасываем | Товары вне пресета не исчезают: они в блоке «Not in this ranking» с причиной |

## 2. Принципы

Каждый принцип: правило, зачем, как применено, как проверить.

**2.1. Данные и есть интерфейс.** Рамок, иконок и подписей ровно столько,
сколько нужно, чтобы прочитать числа. Применено: строка рейтинга — это
цена за единицу, банка, рейтинг и действие; всё остальное раскрывается по
требованию. Проверка: закройте глаза на всё, кроме чисел, — страница должна
остаться понятной.

**2.2. Каждое число отвечает на вопрос «откуда».** Нажатие на число
показывает источник, способ расчёта и дату. Там же — «This number is wrong»:
отчёт об ошибке привязан к конкретному полю, а не к странице вообще.
Проверка: для любого числа на экране можно назвать строку фида, этикетку или
формулу, из которой оно получено.

**2.3. Неизвестное — это состояние, а не пустота.** У каждого «unknown»
есть причина и то, что изменит состояние («Appears once its label is
entered»). Проверка: поиском по сборке нет «$0.000», «NaN», пустых ячеек.

**2.4. Числа набираются как числа.** Число и единица через неразрывный
пробел (`202.041 mg`), табличные цифры, выравнивание по правому краю в
колонках, одна точность в колонке (цена за единицу — три знака доллара),
разряды через локаль, настоящий знак минус и знак умножения ×. Проверка:
колонки ровные по разрядам на любом наборе данных.

**2.5. Кнопка называет действие и его последствие.** «Buy on iHerb», а не
«Go» и не «Buy now». Раскрытие комиссии в том же блоке, выше линии сгиба
(И4). Проверка: по одной надписи кнопки понятно, куда уйдёт человек.

**2.6. Не уводить человека из контекста.** Подробности товара раскрываются
под строкой, список остаётся на месте. Отдельная страница товара остаётся
для ссылок и поисковиков, но сравнивать удобнее, не уходя из списка.

**2.7. Отклик мгновенный, состояние в адресе.** Смена пресета без
перезагрузки; выбранный пресет в адресе, чтобы ссылкой делились с тем же
видом. Без JavaScript страница полная и показывает пресет по умолчанию.

**2.8. Анимация объясняет изменение, а не украшает.** Разрешено: строки
переезжают на новые места при смене порядка (FLIP, до 320 мс), раскрытие по
высоте, подсветка точки на оси при наведении на строку. Запрещено:
анимация, которая задерживает ввод или прячет данные до окончания.
`prefers-reduced-motion` отключает всё. Выразительная анимация живёт только
на главной-истории, и страница рейтинга её не грузит.

**2.9. Без «Вы уверены?».** Действия либо безопасны, либо обратимы. Отчёт
об ошибке — одно поле и одна кнопка; после отправки сказано, что будет
дальше.

**2.10. Сообщение говорит, что произошло и что делать.** Не «Ошибка», а
«Could not send the report. Please try again later.»; не «Нет данных», а
причина и условие появления.

**2.11. Сравнение на одной оси.** Над списком — все товары на одной
логарифмической оси цены за единицу с медианой. Видно разброс («spread
65×») и место любого товара; наведение связывает точку и строку.

**2.12. Полезное состояние по умолчанию.** Страница открывается с
заполненным списком и выбранным пресетом, не с пустым поиском или
приглашением что-то выбрать.

**2.13. Клавиатура — полноправный способ работы.** `1`–`3` переключают
пресеты, `Esc` закрывает карточку источника, фокус всегда виден.

**2.14. Текст — короткий и прямой.** Активный залог, без канцелярита и
восклицаний, названия как их знает человек («servings», а не «units»).
Английский интерфейс: кавычки “ ”, тире —; русский: «», —.

**2.15. Телефон первым.** Ключевое число в первой строке карточки, без
горизонтальной прокрутки страницы; широкие таблицы прокручиваются в своём
контейнере.

## 3. Токены

Цвет (светлая тема, тёмная — в прототипе): фон `#e9ecf0`, поверхность
`#ffffff`, текст `#0e1116`, вторичный `#5a6370`, линии `#d5dae1`, акцент
кобальт `#2f49ff` (выделенный товар, источник, фокус), предупреждение
`#7a5200` на `#fbf1dc`. Зелёный не используется: И8, стиль не похож на iHerb.

Шрифт: Archivo (ось ширины: шире снаружи, уже внутри расчётов), IBM Plex
Mono для чисел. В продукте — самостоятельный хостинг и подмножество глифов;
до решения по бюджету шрифтов страница рейтинга использует системные шрифты
(ADR 0016).

Движение: 200–320 мс, `cubic-bezier(.2,.7,.2,1)`, только `transform`,
`opacity` и высота раскрытия.

## 4. Границы фазы 1

Прототип приложения не добавляет запрещённого §2 спецификации: ввода своей
дозы, истории цен, эквивалентов, алертов, фильтров. Кандидаты для фазы 2,
вытекающие из принципов выше: доза пользователя и цена в день (`C_day`),
фильтры с числом результатов, история цены на той же оси.
