# label-assist (не начато)

Черновой разбор фотографий этикеток для помощи ручному вводу (спецификация
§3.2). Python, одноразовый код, низкие требования к надёжности.

Контракт:

- вход — фото этикетки, сделанное человеком (не страница магазина, И1);
- выход — JSON той же формы, что `catalog_core::schema::LabelFile`
  (`data/labels/<iherb_id>.toml`), где каждая строка имеет
  `confidence = "recognized"`, а `verified_by` пусто;
- человек сверяет черновик с фото, переводит строки в `verified`, заполняет
  `verified_by`/`verified_at`, сохраняет TOML в `data/labels/` и запускает
  `vitrina import-labels`;
- инструмент не пишет в базу и не участвует в ежедневной задаче.

Задача в `docs/backlog.md`, этап M2.
